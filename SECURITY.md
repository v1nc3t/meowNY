# Security

## Reporting a problem

Please do not open a public issue. Report it privately on GitHub: the repository's **Security** tab, then
**Report a vulnerability**. You will get an answer within a week.

Helpful to include: what you found, how to reproduce it, and which version or commit.

## Supported versions

meowNY is a pre-release. Only the latest release gets fixes.

## Scope

Anything that could expose or change someone's data: the encrypted database and its keys, the phone sync, backups,
documents, bill codes and the local command line API. How these are built: [docs/](docs/). What the app stores and
sends: [privacy](https://v1nc3t.github.io/meowNY/guide.html#privacy).
