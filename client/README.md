# meowNY client

React 19 and Vite app. In development it runs on `http://127.0.0.1:5173` and proxies `/api` to the API on port 3000.

From the repo root, after `npm install`:

```bash
cd client
npm run dev      # dev server
npm run build    # typecheck, then production build into dist/
npm run lint
npm test         # date and money helpers
```

See the root `README.md` for the full setup.
